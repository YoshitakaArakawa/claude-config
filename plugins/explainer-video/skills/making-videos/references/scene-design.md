# Scene Design

## スクリプトとの約束

render / stills / capture / verify の各スクリプトは、scene.html に次を求める。

| 名前 | 内容 |
|---|---|
| `window.seek(t)` | 動画の t 秒の画面を描く。同じ t なら必ず同じ画面になる（乱数・現在時刻・CSS アニメーションを使わない） |
| `window.DURATION` | 動画の長さ（秒） |
| `window.SCENES` | `[{ id, start, end }]`（動画の秒）。`stills --scenes` と capture の場面ごとの文字に使う。任意 |

CSS の `transition` や `animation` は実時間で動くので、seek と同期しない。動きはすべて seek の中で、t から計算して style に書く。

## 時間の書き方

- 場面は `<section class="scene" data-dur="秒">` で、文書の並び順に再生される。各場面の開始時刻はテンプレートが積み上げて計算する
- 場面の中の要素は `data-t="出現"` か `data-t="出現,消滅"` で、**場面開始からの秒数**を書く
- 消滅を省くと、場面の終わりまで残る

### 時刻を場面内の相対値で書く理由

- 全体の通し時刻で書くと、ある場面の尺を変えたとき、後ろの全要素の時刻をずらす作業が要る
- 消えない要素に番兵値（例：99）を置くと、尺を伸ばしたときにその値を超えた要素が途中で消える。番兵が要らない書き方にしておく

通し時刻で書いた既存の HTML を扱う場合は、番兵を 999 以上にするか `Infinity` として扱う。

## 場面の切り替え

- 前の場面が消え切ってから、次の場面を出す。前後の文字がクロスフェードで重なると読めない
- 間の無地は 0.3 秒程度にする（テンプレートの `GAP`）。1.5 秒の無地は止まったように見える
- 同じ位置での前後比較（変更前の画像が変更後に変わる）は、場面の切り替えではなく場面内の `FX` で行う

## 速度

- コンテンツ時間と動画時間を分ける：`seek(t) = seekContent(t * SPEED)`。全体の速さは `SPEED` だけで変える
- `SPEED` を上げたら、文字量の多い場面だけ `data-dur` を延ばすか、2 拍（2 つの場面か、時間差で出す 2 つの塊）に割る。読み切れるかは capture の `onscreen-text.md` の表示秒数で確かめる

## 動きの型を混ぜる

全カットを同じテンプレートにしない。次のような型を混ぜる。

- 前後を左右に並べ、矢印でつなぐ
- 同じ位置でクロスフェードし、消えたもの・現れたものに枠を付ける
- 3 つ以上の版を同じ縮尺で並べる
- 変わった箇所を原寸近くで切り出し、全体図の横に添える
