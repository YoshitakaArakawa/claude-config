# Localizing

## 手順

1. 元の言語の `scene.html` を確定させる（レビュー反映後）。他言語版は元の版からの派生として作り、両方を並行して編集しない
2. 置換スクリプト（例：`make-en.py`）を作る。文言を「原文 → 訳文」の対応で 1 件ずつ置き換える
3. 置換スクリプトを実行して `scene-en.html` を書き出す
4. 下の検査を通してから、stills で全場面を目視し、render する

## 置換スクリプトの書き方

- 置換関数は、原文が見つからなければ失敗させる（`assert 原文 in s`）。黙って置換漏れを出さない
- 置換は HTML 全体に対して行う。JS 内の文字列（場面データの配列など）も対象に含める
- JS の文字列を訳すときは、引用符の衝突に注意する。英語のアポストロフィ（`don't`）が `'...'` の中に入ると構文が壊れる。エスケープするか、タイポグラフィの引用符（`’` `“ ”`）を使う
- `<html lang>` を書き換える

## 検査

- **元の文字の残り**：置換後の HTML に元言語の文字が残っていないか、正規表現で列挙する。日本語なら次の範囲を検査する

  ```python
  left = sorted(set(re.findall(r'[぀-ヿ㐀-鿿＀-￯「」、。]+', s)))
  ```

- **構文**：ブラウザで開き、コンソールにエラーが出ないこと（stills が撮れれば JS は動いている）
- **はみ出し**：英語は横に長い。見出しの文字サイズと改行位置を調整し、全場面を stills で確認する

## 書体

欧文フォントを先に指定し、和文フォントを後ろに残す（例：`'Inter','Noto Sans JP',sans-serif`）。Web フォントの読み込み URL にも欧文フォントを足す。
